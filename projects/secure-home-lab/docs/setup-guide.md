# Secure Home Lab - Setup Guide

## Prerequisites
- Windows PC with **at least 16GB RAM** (24GB+ recommended)
- 50GB+ free disk space
- VirtualBox (latest version) + Extension Pack

## Step 1: Install VirtualBox
1. Go to [virtualbox.org/wiki/Downloads](https://www.virtualbox.org/wiki/Downloads)
2. Download and install **VirtualBox**
3. Download and install the **Extension Pack** (same page)

## Step 2: Download the ISOs
- **Kali Linux**: [https://www.kali.org/get-kali/](https://www.kali.org/get-kali/)
- **pfSense**: [https://www.pfsense.org/download/](https://www.pfsense.org/download/)
- **Windows 11 Evaluation**: [https://www.microsoft.com/en-us/evalcenter/evaluate-windows-11-enterprise](https://www.microsoft.com/en-us/evalcenter/evaluate-windows-11-enterprise)

# Secure Home Lab Setup Guide

## Prerequisites
- Windows PC with at least 16GB RAM
- VirtualBox (latest version) + Extension Pack
- ~50GB free disk space

## Step 1: Install VirtualBox
1. Download from [virtualbox.org](https://www.virtualbox.org/)
2. Install + Extension Pack

## Step 2: Download ISOs

- pfSense: https://www.pfsense.org/download/
- Windows 11 Evaluation: https://www.microsoft.com/en-us/evalcenter/evaluate-windows-11
